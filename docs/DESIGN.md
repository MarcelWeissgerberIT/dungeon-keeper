# Independent design and source notes

The historical reference was the original 1997 PC manual, read as an archived scan: [Dungeon Keeper manual](https://images2.wikia.nocookie.net/__cb20120720033242/dungeonkeeper/images/c/cb/Dk_manual-en.pdf). The manual itself is not redistributed here.

General design principles studied: designate excavation; workers claim exposed terrain; build on claimed ground; haul mined gold into limited storage; provide food, rest and periodic pay; rooms influence arrivals and jobs; training consumes resources; research unlocks powers; workers and fighters act autonomously; defend the settlement centre. These principles were independently programmed with new numbers, a new map generator, original names and a different four-invasion victory condition.

Kluftkrone has its own title, amber mineral monument, creature designs, locations, room imagery, user interface, musical motif, synthesized sounds and display font. No original executable, source code, artwork, manual text, map, dialogue, sound recording or musical composition is included. The game does not claim endorsement or affiliation with another title or publisher. The supplied repository path is retained; it is not the game's product title.

A first title candidate was discarded after finding games already using it. A public exact-name search on 2026-09-09 found no result for “Kluftkrone”; this is not a comprehensive trademark clearance.

## Relevant primary sources

- [German Copyright Act §69a(2)](https://www.gesetze-im-internet.de/urhg/__69a.html): distinction between program expression and underlying ideas/principles.
- [CJEU C-406/10, official summary](https://curia.europa.eu/jcms/upload/docs/application/pdf/2012-05/cp120053en.pdf): functionality and expression, including independently protected manual material.
- [CJEU C-355/12, official summary](https://curia.europa.eu/jcms/upload/docs/application/pdf/2014-01/cp140009en.pdf): video games can contain protected graphic and audio expression.
- [UrhG §23](https://www.gesetze-im-internet.de/urhg/__23.html), [MarkenG §14](https://www.gesetze-im-internet.de/markeng/__14.html), [UWG §4(3)](https://www.gesetze-im-internet.de/uwg_2004/__4.html): adaptations, trademark confusion and unfair imitation require separate consideration.

The implementation aims to maintain independent expression; this design record does not guarantee legal clearance or trademark availability.

## Visual reference review

The 2026-09-09 revision additionally compared twelve historical images in the [GOG gallery](https://www.gog.com/en/game/dungeon_keeper) and this [original gameplay screenshot](https://freebie.games/wp-content/uploads/2023/08/Dungeon-Keeper-gallery-02.png). The observations informed general visual principles: a close oblique view, heavy textured wall flanks, many small pavers, warm local light, distinct creature silhouettes, and one continuous side command panel. The new copper/basalt panel, mineral furnace, fissure portal, gauntlets, creatures and furnishings use independent designs. Reference screenshots are not distributed.
